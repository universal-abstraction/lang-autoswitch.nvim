*lang-autoswitch.txt*   Keyboard layout switching for Hyprland and Sway

==============================================================================
INTRODUCTION                                               *lang-autoswitch*

lang-autoswitch.nvim switches the keyboard layout to your default one in
Normal mode and back to the layout you were typing in when you enter Insert
mode or leave Neovim. It uses Hyprland's `hyprctl` or Sway's `swaymsg`.

- On startup, |FocusGained| and |InsertLeave| the default layout is set and
  the previous layout is remembered.
- On |InsertEnter|, |FocusLost| and exit the remembered layout is restored,
  if the plugin switched away from it and the current layout is still the
  default one.

==============================================================================
REQUIREMENTS                                  *lang-autoswitch-requirements*

- Neovim 0.10+ (uses |vim.system()|)
- Hyprland with `hyprctl` in PATH, or Sway with `swaymsg` in PATH

==============================================================================
SETUP                                                *lang-autoswitch-setup*

With lazy.nvim:
>lua
  {
    "universal-abstraction/lang-autoswitch.nvim",
    main = "lang_autoswitch",
    opts = {
      backend = "hyprland",
      backend_config = {
        default_layout = "us",
        layouts = { "us", "ru" },
      },
    },
  }
<
Without a plugin manager:
>lua
  require("lang_autoswitch").setup({
    backend = { name = "sway", default_layout = "English (US)" },
  })
<
==============================================================================
OPTIONS                                            *lang-autoswitch-options*

backend (string|table)                          Default: "hyprland"
  "hyprland" or "sway"; an inline config such as
  `{ name = "sway", default_layout = "English (US)" }`; a backend module with
  a `new(cfg)` constructor; or a backend object created by one. An unknown
  name is reported as an error and the plugin stays inactive.

backend_config (table|nil)                      Default: nil
  Backend options, see |lang-autoswitch-backend-config|.

set_on_vimenter (boolean)                       Default: true
  Set the default layout on |VimEnter|.

set_on_focus_gained (boolean)                   Default: true
  Set the default layout on |FocusGained|.

set_on_insertleave (boolean)                    Default: true
  Set the default layout on |InsertLeave|.

restore_on_insert (boolean)                     Default: true
  Restore the previous layout on |InsertEnter|. If false, the default
  layout is set instead.

restore_on_focus_lost (boolean)                 Default: true
  Restore the previous layout on |FocusLost|.

restore_only_if_default (boolean)               Default: true
  Restore only if the current layout is still the default one, so a layout
  you chose yourself is not overwritten.

log_level (string|number)                       Default: "warn"
  "trace", "debug", "info", "warn", "error" or a |vim.log.levels| value.

cache_ttl_ms (number)                           Default: 1000
  Passed to the backend as its cache lifetime for keyboard queries.

debounce_ms (number)                            Default: 75
  Ignore repeated switches of the same kind within this many milliseconds.

focus_lock (boolean)                            Default: true
  Serialise focus transitions between Neovim instances, see
  |lang-autoswitch-focus-lock|.

focus_lock_path (string|nil)
  Lock directory. Default: `stdpath("state") .. "/lang-autoswitch.lock"`.

focus_lock_ttl_ms (number)                      Default: 2500
  Age after which another instance may take the lock over.

focus_lock_poll_ms (number)                     Default: 50
  Retry interval while waiting for the lock.

==============================================================================
BACKEND CONFIG                              *lang-autoswitch-backend-config*

Hyprland:
  default_layout (string)
    Layout for Normal mode. Default: "us".
  device (string|nil)
    Keyboard name from `hyprctl devices -j`. Default: the main keyboard.
  layouts (table|nil)
    Layout codes in the order configured in Hyprland, e.g. { "us", "ru" }.
    Default: read from the keyboard.

Sway:
  default_layout (string, required)
    Layout name as Sway reports it, e.g. "English (US)".
  device (string|nil)
    Keyboard identifier from `swaymsg -t get_inputs`. Default: the first
    keyboard.
  layouts (table|nil)
    Layout names in the configured order. Default: read from the keyboard.

==============================================================================
FOCUS LOCK                                      *lang-autoswitch-focus-lock*

When you switch between two Neovim windows, one gets |FocusLost| and the
other |FocusGained| at almost the same time. The lock makes the second one
wait until the first has restored its layout.

An instance holds the lock while it has focus. A lock older than
`focus_lock_ttl_ms` is taken over by the next instance instead of waiting,
so a missing |FocusLost| event can't block it; the previous owner then skips
its restore. Since a lock held for a while is older than the TTL, the
ordering is best-effort.

COMMANDS                                          *lang-autoswitch-commands*

:LangAutoswitchSelfCheck                            *:LangAutoswitchSelfCheck*
  Check that the backend is available and report the detected keyboard and
  current layout.
